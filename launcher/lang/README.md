# Launcher languages

The `.po` files are the translations of [KeeperFX's launcher](https://github.com/dkfans/keeperfx-launcher-qt)
(`i18n/translations_*.po`, GPL v2), the work of the KeeperFX launcher's translators. Endless Keeper's launcher uses
them for every text the two launchers share, so its settings read the same as KeeperFX's in each language.

`own.txt` holds the translations of the texts only Endless Keeper's launcher has.

To update: copy the newer `.po` files from KeeperFX's launcher over these.
