# Neighbours

> [!NOTE]
> This is a planned feature. It is not in the game yet, and details may change before it arrives.

Rooms care what they touch. For example:

- A Torture Chamber sharing a wall with the Prison converts captives faster.
- A Library beside the Temple reads forbidden things sooner, and its Warlocks pray more.
- A Lair touching a Hatchery lets creatures eat without leaving it.
- A Graveyard beside a Lair upsets everyone but Vampires.

Six pairs to begin with, each shown as a line of light along the shared wall. Some pairs pull against each other,
so no plan has everything.
