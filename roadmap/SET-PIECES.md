# Set Pieces

> [!NOTE]
> This is a planned feature. It is not in the game yet, and details may change before it arrives.

Places drawn by hand, set down in a generated world. Small pieces are made in the map editor, each for a biome, a
[circle](CIRCLES-OF-HELL.md) and a size, and the world places them in its caves and strongholds. For example:

- A floor laid out like a chessboard, with traps and special boxes on its squares.
- A run of rolling boulders.
- A long corridor a single slab wide, with Word of Power traps all the way down.
- A row of cells, with a Horned Reaper locked in the last one.

Any one piece is rare in a world, and it is turned or mirrored when it is placed, so you seldom meet the same piece
the same way round.
